# projeto-medusa-kali.
Projeto de Cybersegurança — Kali Linux e Medusa

Sobre o projeto

Este projeto faz parte dos meus estudos de Cybersegurança na plataforma DIO.

O objetivo é aprender sobre ataques de força bruta, auditoria de segurança e proteção de sistemas utilizando Kali Linux e Medusa.

Ferramentas utilizadas

- Kali Linux
- Medusa
- Nmap
- Metasploitable 2
- DVWA
- VirtualBox

Objetivos

- Aprender reconhecimento de serviços com Nmap.
- Entender como funciona um ataque de força bruta.
- Conhecer a ferramenta Medusa.
- Criar listas de usuários e senhas para laboratório.
- Aprender formas de proteger sistemas contra tentativas indevidas de acesso.

Ambiente de testes

Os exercícios serão realizados em ambiente virtual controlado, utilizando máquinas vulneráveis próprias para estudo.

Atividades práticas

As atividades serão documentadas conforme forem realizadas durante o curso.

Medidas de segurança

- Utilização de senhas fortes.
- Autenticação em dois fatores.
- Bloqueio de tentativas excessivas.
- Monitoramento de acessos suspeitos.

Conclusão

Este projeto representa minha jornada de aprendizado em Cybersegurança, com foco em segurança ofensiva, identificação de vulnerabilidades e proteção de sistemas.
